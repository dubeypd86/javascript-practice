# JavaScript Practice & Projects

A collection of JavaScript practice exercises, concepts, and mini-projects.

## 📁 Repository Structure

- **`DOM/`** — DOM manipulation exercises and learning materials.
- **`EVENT-LISTENER/`** — Event handling, bubbling, capturing, and practical event listener examples.
- **`search engine/`** — A mini search engine interface built with HTML, CSS, and Vanilla JavaScript.
- **`Storage/`** — Web Storage API demonstrations (localStorage / sessionStorage).
- **`TIME INTERVAL/`** — Timing events using `setInterval` and `setTimeout`.

## 🚀 Getting Started

To explore any project or topic:
1. Clone or download this repository.
2. Open any topic folder.
3. Open the corresponding `index.html` directly in your browser.
